# Basic Calculator
This is my variation of a simple calculator.
This calculator has buttons from 0-9, addition, subtraction, equals, and clear capabilities.
The audience for this app is whoever needs a simple calculator for addition and subtraction. 
Furthermore, this app can be used as a skeleton for future, more complex, calculator apps.
There are already many apps like this, but it can still be useful, and its good to know how to code a basic calculator app because it can have many different applications.
